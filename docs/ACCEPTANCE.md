# AgentDock V0.2 测试与验收说明

最后测试日期：2026-11-17

## 自动化验证

在 Node.js v22.16.0 Linux 容器环境执行：

```bash
npm run check
npm test
```

本地结果：25/25 测试通过。HTTP `GET /api/health` 返回 `{ "status": "ok", "version": "0.2.0" }`。

覆盖：
- 项目路径越界与符号链接检查，持久化、停止及队列
- Demo Agent、受限任务、可写任务审批及拒绝、失效审批 ID
- 重启后不恢复任务队列或待授权请求
- 本地 HTTP 路由权限、Origin/Host 拦截、上传限制
- 文件名搜索过滤、项目内文件下载和越界拒绝
- 三类 CLI 的 *模拟* NDJSON 子进程、Token 数据、退出失败、停止和活动脱敏

## 安全说明

`edit` 是任务级前置确认，不意味着操作系统隔离、每次工具调用都经过批准或保证只修改项目目录。
`plan` 模式的具体权限边界取决于 CLI 实现。仅在可信工作区中运行，不要公网暴露 4173 端口。

## 仓库同步

当前本地源码与测试随 V0.2 ZIP 交付。直到 GitHub `main` 出现 `package.json`、`src/`、`public/`、`test/` 等文件，并且 CI 运行成功，不能把仓库视为已完成同步。
