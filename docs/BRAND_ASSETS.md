The logos in the Agent rail identify compatible CLI integrations; they do not represent AgentDock branding, partnership or endorsement. They are bundled locally, so there is no third-party image CDN request.

- `public/brands/codex.svg`: symbol reference https://thesvg.org/icon/codex ; product https://openai.com/codex

- `public/brands/antigravity.svg`: one-color mark reference https://thesvg.org/icon/antigravity-google ; Google official press assets https://antigravity.google/press

These source pages do not grant trademark permission. Vendor marks and names remain their owners' property. Review the latest OpenAI, Anthropic and Google brand rules before distributing AgentDock publicly or commercially. Do not stretch, recolor, combine them with AgentDock's brand, or imply official affiliation. Use neutral initials if permissions are unavailable.

The built-in Demo symbol is separate. If any branded image fails to load, the UI displays its two-letter label without breaking navigation.
